# Northfit E-commerce

Northfit is a full-stack fashion e-commerce platform built as a portfolio project.

## Project Goals

* Build a realistic fashion e-commerce workflow
* Practice Java backend development with Spring Boot
* Practice RESTful API design
* Design and implement a relational database
* Practice authentication and role-based authorization
* Apply testing, caching, rate limiting and Docker
* Explore realtime features and AI-powered shopping assistance

## Tech Stack

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui
* Lucide React
* React Router

### Backend

* Java
* Spring Boot
* Spring Security
* JPA / Hibernate
* MySQL or PostgreSQL
* Redis

### Engineering

* Git / GitHub
* Docker
* OpenAPI / Swagger
* JUnit / Mockito
