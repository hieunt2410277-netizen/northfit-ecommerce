# Coolmate Design System

## Brand direction

Coolmate is a clean, athletic, modern apparel store. The interface prioritizes scanability, high-contrast purchase actions, accessible controls, and frictionless commerce.

## Colors

| Token | Value | Usage |
|---|---|---|
| Primary black | `#111111` | Text, primary actions, selected states |
| Secondary black | `#222222` | Headings and emphasis |
| Subtext | `#666666` | Supporting copy and metadata |
| Border | `#E5E7EB` | Cards, fields, dividers |
| Surface muted | `#F8F9FA` | Secondary sections and panels |
| Brand blue | `#2F5ACF` | CoolClub and member actions |
| Brand blue dark | `#1D2A68` | Rewards banners |
| Sale red | `#E11B22` | Sale and validation states |
| Promo orange | `#F97316` | Discount and coupon states |

## Typography

Use an expressive sans-serif display face for brand headings and a readable sans-serif for body copy. Keep product titles compact, prices prominent, and metadata secondary.

- Hero and product title: 24px or larger, bold
- Section title: 20px, bold
- Body: 14px, regular
- Caption and badges: 12px, medium or bold

## Layout

- Use a 4px spacing grid
- Desktop content max width: 1280px
- Checkout content max width: 1152px
- Minimum mobile tap target: 44px
- Product grid: 1-2 columns mobile, 3 tablet, 4 desktop
- Desktop product detail uses a persistent purchase panel
- Mobile product detail uses a sticky bottom purchase bar

## Components

### Product card

Use an aspect-ratio image area, compact sale badge, product title, color options, price, original price, and discount label.

### Primary action

Use a black, high-contrast, rounded button with a minimum height of 48px. Disabled actions use neutral gray.

### Form fields

Use full-width rounded fields, visible labels, clear validation, and keyboard-accessible focus states.

### Coupon and loyalty surfaces

Use dashed coupon cards and blue CoolClub surfaces. Show eligibility, expiry, and minimum-spend information clearly.

### Responsive behavior

On mobile, collapse navigation and filters into accessible controls and keep checkout actions reachable without excessive scrolling.
