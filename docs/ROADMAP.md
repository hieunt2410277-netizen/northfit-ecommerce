# Coolmate Roadmap

## Phase 1: Foundation

- Restore and validate frontend and backend build tooling
- Establish the Coolmate design tokens
- Configure local MySQL and H2 test profile
- Add authentication foundations

## Phase 2: Storefront

- Homepage and navigation
- Product listing, search, filters, and sorting
- Product detail and variant selection
- Cart and checkout

## Phase 3: Orders and administration

- Order history and tracking
- Product CRUD
- Inventory management
- Admin order and user management

## Phase 4: Quality and production readiness

- API documentation
- Unit, integration, and end-to-end tests
- Docker development environment
- Security hardening and observability

## Phase 5: Advanced capabilities

- Redis caching
- Rate limiting
- OAuth
- Realtime notifications
- AI shopping assistant
